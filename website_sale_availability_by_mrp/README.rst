====================================
Availability by Manufacturing Orders
====================================

Este módulo amplía la disponibilidad del sitio web para tener en cuenta las
órdenes de fabricación.

Depende de ``website_sale_availability_by_po`` y mantiene separada la
dependencia de fabricación, de forma que los clientes que solo necesitan
disponibilidad por compras no tienen que instalar ``mrp``.
