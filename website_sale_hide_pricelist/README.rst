Uso
===

Este módulo modifica las plantillas del sitio web para evitar que se muestren las tarifas aplicadas a los productos cuando se utilizan listas de precios en la vista de catálogo.

No requiere configuración adicional. Una vez instalado, las tarifas dejarán de mostrarse en el listado de productos.

- En "Website > Shop > Edit > Customize > Hide Pricelist Selector" habilitamos o
  deshabilitamos la visualización del selector de tarifas siendo mostrado cuando el
  selector esta deshabilitado y siendo invisible cuando el selector esta habilitado.
