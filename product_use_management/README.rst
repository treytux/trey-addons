======================
Product use management
======================

|badge1|

    * Módulo para gestionar el número de usos de un producto.
    * Se añade un check "Gestión de usos" en la ficha del producto.
    * Cuando se marca el campo "Gestión de usos" se muestran los nuevos campos "Número de usos" y "Veces usado".
    * Se añade un campo calculado "Usos pendientes".
    * Cada vez que se confirme el movimiento de un producto se guarda la fecha.
    * Cuando los campos "Número de usos" y "Veces usado" sean iguales se lanza una inspección y si es positiva se recarga el número de usos.
