Sale Order Invoice Date Due
===========================

Este módulo añade un campo de fecha vencimiento de factura en los pedidos de
venta de manera que el usuario pueda establecer una fecha de vencimiento para la
factura si en el pedido no está establecido el campo plazos de pago.
