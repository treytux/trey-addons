==========================
Website Lite YouTube Embed
==========================

Descripción
===========

Este módulo añade un snippet de Website para insertar vídeos de YouTube con
``lite-youtube-embed``.

Funcionalidad principal:

- Snippet arrastrable ``Lite YouTube`` en el editor de Website.
- Campo de configuración ``YouTube URL`` en opciones del snippet.
- Normalización automática de URL (watch, embed, youtu.be, http/https).
- Configuración de tamaño mediante ``Width`` y ``Height``.
- Carga diferida del reproductor real al hacer clic (fachada ligera).
