=========================
Sale order notifiy groups
=========================

Este módulo mejora el sistema de notificaciones de los pedidos de venta a los
seguidores dependiendo del grupo al que pertenecen.

Los seguidores se identifican en cinco grupos:
- user
- portal
- portal_customer
- follower
- customer

Por defecto en el grupo de follower en las notificaciones se envía un botón para
acceder al documento, en este caso el pedido de venta, con este módulo este
comportamiento se modifica, para que solo se mande el botón a los del grupo user.
