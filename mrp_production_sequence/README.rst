MRP Production Sequence
=======================

Este módulo agrega el campo "Secuencia" a la vista de "Órdenes de producción"
para poder ser ordenadas.

Uso
===

- En el módulo "Fabricación" ir a "Operaciones > Órdenes de producción".
- Hacer clic y arrastrar en el icono de la cruceta para alterar el orden de los
 elementos.
