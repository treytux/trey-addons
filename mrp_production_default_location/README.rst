Uso
===

Este módulo permite modificar las ubicaciones por defecto en las órdenes de producción.
Al instalarlo, se añaden configuraciones que permiten definir y ajustar las ubicaciones predeterminadas que se usarán en las fabricaiones.

Configuración
=============

Para configurar las ubicaciones por defecto en la compañía:

1. Ir a *Ajustes > Compañías*.
2. Seleccionar la compañía deseada.
3. En la pestaña **Fabricación**, establecer las ubicaciones de origen y destino predeterminadas para las órdenes de producción.
4. Guardar los cambios.
