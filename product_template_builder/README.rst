Product Template Builder
========================

Este módulo permite crear plantillas de producto que permitan crear productos a
partir de ciertos campos previamente establecidos.

**Tabla de contenidos**

.. contents::
   :local:

Utilización
===========

- En "Inventario > Configuración" haremos clic en "Constructor de plantillas de
producto".
- Crearemos una plantilla nueva con la información por defecto que queramos.
- Una vez estemos en la "Inventario > Datos principales > Productos" crearemos
un producto nuevo y escogeremos la plantilla "anteriormente creada" en la
sección de "Información general" en el campo "Plantilla de producto".
- Se puede añadir la plantilla como plantilla por defecto al crear un producto desde ir.default.
