Este módulo añade un botón inteligente (smart button) de escandallo en las órdenes de fabricación.

**Tabla de contenidos**

.. contents::
   :local:

Uso
===

#. Ir a *Fabricación > Órdenes de fabricación*.
#. Abrir cualquier orden.
#. Se mostrará un nuevo botón inteligente llamado *Escandallo* que permite visualizar o acceder al desglose del producto.
