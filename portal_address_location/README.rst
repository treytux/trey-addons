Portal Address Location
=======================

Integra el autocompletado de localidades y códigos postales en el formulario
de datos del portal ``/my/account``.

Funcionalidades
===============

- Busca localidades y códigos postales desde el portal.
- Completa ciudad, provincia, país y código postal.
- Valida la ubicación seleccionada antes de guardar el contacto.
- Utiliza la lógica reutilizable de ``address_location_autocomplete``.
