# Portal address location integration

## Alcance

El módulo integra `address_location_autocomplete` en `/my/account` y conserva
la validación de `zip_id` antes de guardar los datos del contacto.

## Dependencias

La búsqueda y el widget pertenecen al módulo base reutilizable. Este módulo
solo aporta la vista portal y la adaptación de los datos del formulario.
