Sale sale invoice policy return
===============================

Permite aplicar la política de facturación correcta en las devoluciones.

Cuando un pedido usa facturación por pedido el módulo se asegura de que para
los productos físicos solo se pueda facturar la cantidad que realmente se ha
entregado (facturado). Solo si ya ha habido al menos una entrega.

Los servicios no se ven afectados.
