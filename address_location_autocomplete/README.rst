=============================
Address Location Autocomplete
=============================

Módulo base reutilizable para completar direcciones utilizando los datos
locales de Odoo.

Funcionalidades
===============

- Busca localidades y códigos postales.
- Permite filtrar los resultados por país.
- Completa ciudad, provincia, país y código postal.
- Expone una ruta JSON y un widget JavaScript configurable.
- Puede integrarse en formularios de portal, comercio electrónico y envío.
