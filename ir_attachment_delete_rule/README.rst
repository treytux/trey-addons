Este módulo añade un grupo de seguridad y una regla que permite eliminar archivos adjuntos en Odoo.

**Tabla de contenidos**

.. contents::
   :local:

Uso
===

Una vez instalado el módulo:

#. Dirígete a *Ajustes > Usuarios y compañías > Grupos*.
#. Asigna el grupo correspondiente al usuario que deba tener permisos para eliminar adjuntos.
#. Los usuarios con este grupo podrán eliminar adjuntos desde cualquier modelo que utilice `ir.attachment`.
