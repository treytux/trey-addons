Smartsupp chat integration with website

Este módulo integra la funcionalidad del Smartsupp chat con el sitio web.

  • Créditos
    • Autor

Uso

  1. Ir a Sitio web > Configuración > Ajustes > Sitio web.
  2. Activar la casilla de verificación Smartsupp.
  3. Añadir el código de instalación facilitado por Smartsupp.
  4. Hacer clic en el botón "Guardar".
