Website sale searchable text

Compute relevant product fields on searchable text

Añade un campo calculado y almacenado searchable_text en la plantilla de producto que reúne el nombre, la descripción web sin HTML, el campo hidden_mapping y las referencias internas de todas las variantes.

El campo hidden_mapping permite introducir términos de búsqueda adicionales (sinónimos, nombres alternativos) que no se muestran en la ficha pública pero sí hacen que el producto aparezca en el buscador de la tienda web.

El módulo registra searchable_text como campo de búsqueda de la tienda web, de modo que el buscador de /shop y su autocompletado también consultan ese contenido.
