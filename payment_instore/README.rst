===============
Payment InStore
===============

Este módulo permite realizar pagos mediante TPVs con la API InStore.

Configuración
=============

En la configuración del proveedor de pago, establecer la siguiente configuración

* **InStore appconector key**: Clave API del comercio InStore.

* **InStore URL base**: URL o IP del dispositivo TPV.


Nota
~~~~

Se puede realizar una prueba de conexion con el dispositivo en el proveedor de
pago, en el botón 'Prueba dispositivo' habilitado a tal efecto.
