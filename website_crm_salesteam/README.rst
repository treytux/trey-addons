formularios web.

**Tabla de contenidos**

.. contents::

Uso
~~~

- Configura un equipo de ventas en los ajustes del sitio web
  (`website.salesteam_id`).
- Envía un formulario de contacto web.
- El lead creado utiliza ese equipo como `team_id`.
