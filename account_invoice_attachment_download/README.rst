===================================
Account invoice attachment download
===================================

Puede seleccionar varias facturas en el listado para descargar desde "Acción / Descargar adjuntos" todos los ficheros.
Este módulo es útil para descargar los ficheros de facturas adjuntas en las facturas de proveedores.
