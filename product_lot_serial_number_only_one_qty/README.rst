Product Lot Serial Number Only One Qty
======================================


Odoo permite que exista varios quants con cantidad a mano al mismo tiempo para
un número de serie, cuando si se trata de un producto que solo puede existir
una unidad con ese número de serie, no se debería de permitir. Este módulo
añade esta restricción.
