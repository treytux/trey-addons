Product obsolete
================

- Añade a los productos un campo para indicar si el producto está obsoleto.
- Si una plantilla de producto tiene variantes, la plantilla sólo se marcará como obsoleta si todas sus variantes son obsoletas.
- Los productos marcados como obsoletos pueden ser ocultados mediante un filtro desde el listado de productos, desde el listado de los movimientos de stock y en la valoración del inventario.
