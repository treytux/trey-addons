==================================
stock_quant_inventory_import_excel
==================================

Asistente para importar inventario desde Excel.
El asistente pide ubicación y el fichero a importar, el fichero tiene que ser un
fichero Excel con al menos la columna EAN con el código de barras del producto.

Es optativo tener la columna CANTIDAD, si no existe se entiende que su valor es 1.
El asistente agrupa los códigos de barras para sumar la columna CANTIDAD.
