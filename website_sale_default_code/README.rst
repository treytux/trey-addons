Website Sale Default Code
===============================

Descripción
===========

Este módulo nos permite habilitar o deshabilitar la visualización del campo
default_code de los productos en la tienda online. Se puede mostrar en dos campos:
- En la lista de productos.
- En la vista de producto.
Se ha mejorado para que ahora aparezca tambien el checkout de la tienda online
tanto en las lineas del carrito como en el popup del carrito.

Lógica de Visualización
=======================

Botón activo: Se mostrará el código de producto.
Botón inactivo: No se mostrará el código de producto.

Configuración
=============
- En "Website > Shop > Edit > Customize > Internal Reference" habilitamos o
  deshabilitamos la visualización del código de producto.
  Si entramos a la ficha de un producto, también tendremos esta opción.
- En "Website > Shop > Checkout > Edit > Customize > Internal Reference" habilitamos o
  deshabilitamos la visualización del código de producto.
  Tambien aparecera "Internal Reference (Cart Popover)" para el popup del carrito
  que cambiara en toda la web.
