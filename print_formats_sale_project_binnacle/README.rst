Print Formats Sale Project Binnacle
===================================

Este módulo añade la posibilidad de imprimir el informe de bitacora de proyecto
desde los presupuestos/pedidos en ventas.

Uso
----

- Ir a la app Ventas
- Seleccionar un presupuesto/pedido e imprimir el informe "Bitácora de Proyecto".
