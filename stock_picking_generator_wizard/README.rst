Stock Picking Generator Wizard
===============================

Descripción
===========

Este módulo añade un asistente que permite generar en masa albaranes de "asistencia técnica"
en estado borrador para un cliente y producto determinados, calculando la fecha prevista de
cada albarán según una periodicidad configurable (días/meses/años) y una cantidad definida, facilitando la planificación de visitas técnicas sin confirmar los albaranes.
