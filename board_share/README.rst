Permite compartir instantáneas del tablero personal de Odoo con usuarios
concretos para que las consulten en modo sólo lectura.

Uso
~~~

1. Abre ``My Dashboard``.
2. Pulsa el botón ``Share``.
3. Indica el nombre y los usuarios destinatarios.
4. Los destinatarios lo verán en ``Shared Dashboards``.
