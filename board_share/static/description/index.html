Compartir instantaneas de tablero en modo solo lectura

Este modulo permite compartir una instantanea del tablero personal de Odoo con usuarios concretos para que puedan consultarla en modo solo lectura.

El usuario propietario comparte el tablero desde My Dashboard y los destinatarios lo encuentran en el menu Shared Dashboards.

La comparticion se realiza como copia fija del tablero, por lo que los cambios posteriores del propietario no modifican la version ya compartida.
