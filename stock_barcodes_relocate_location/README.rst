================================
Stock barcodes relocate location
================================

.. |badge1| image:: https://img.shields.io/badge/licence-AGPL--3-blue.png
    :target: http://www.gnu.org/licenses/agpl-3.0-standalone.html
    :alt: License: AGPL-3

|badge1|

    * Añade un asistente para reubicar una ubicación completa con lector de códigos de barras.
    * Se definen pasos para leer el código de ubicación a reubicar y el código de la ubicación de destino.
    * Calcula y muestra el listado de todos los productos que se encuentran en la ubicación de origen.
    * El usuario puede eliminar algún producto de la ubicación origen para que no se incluya en el albarán.
    * Añade control de errores.
    * Genera un albarán interno pendiente de validar por el usuario.
    * Para acceder al asistente se añade un menú en Inventario > Operaciones.
    * Añade restricción para que solo algunos usuarios puedan visualizar y utilizar el asistente.
