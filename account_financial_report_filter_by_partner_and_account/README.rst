Account financial report filter by partner and account
======================================================

Cuando se imprime el libro mayor con el filtro de empresa, automáticamente introduce
un filtro para que solo aparezcan las cuentas de pago y cobro. Si se modifica el filtro
de las cuentas contables, entonces no aparece los movimientos filtrados por empresa.

Con este módulo se permite poder filtrar por cuentas contables y empresa al mismo tiempo.
