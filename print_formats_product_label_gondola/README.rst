Este módulo permite la impresión de etiquetas de producto para estanterías del
tipo góndola, imponiendo una etiqueta por producto seleccionado sobre formato
A4.

**Tabla de contenidos**

.. contents::
   :local:

Utilización
===========

- En la vista listado de los productos, seleccionaremos los productos que
queremos imprimir.
- Hacemos click en el desplegable "Más" y a continuación seleccionaremos
"Imprimir etiquetas góndola".
