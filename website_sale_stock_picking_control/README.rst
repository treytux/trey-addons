Este módulo permite controlar la creación automática de albaranes según el
sitio web de origen del pedido de venta.

Configuración
=============

En los ajustes del sitio web se puede activar la opción **Do not create
delivery orders on confirmation**.

Cuando la opción está activa, los pedidos procedentes de ese sitio web se
confirman sin crear albaranes ni movimientos de stock. Los pedidos de sitios
web sin la opción activa mantienen el comportamiento estándar de Odoo.
