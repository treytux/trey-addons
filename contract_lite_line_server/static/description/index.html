Contract Lite Line Server

Añade información de servidor administrado en líneas de contrato y un asistente para actualizar la ocupación de contenedores desde una lectura externa.

Permite registrar servidor, contenedor, espacio contratado, espacio consumido, ampliaciones de disco y saldo actual para detectar sobreconsumos en líneas de contrato.

Incluye una ampliación sugerida basada en crecimiento histórico proyectado a seis meses con buffer de seguridad, un filtro de líneas con saldo negativo y acciones para importar ocupación o notificar a los seguidores del contrato.

La plantilla de notificación es editable desde el backend y se renderiza en el idioma del partner del contrato.
