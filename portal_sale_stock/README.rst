Portal Sale Stock
=================

Customize sale stock portal behaviour.

Key Features
------------
- Customizes the sale stock portal behavior in Odoo.
  
Installation
------------
To install this module, you need to:

1. Add the module to your Odoo addons directory.
2. Update your Odoo module list.
3. Install the module through the Odoo interface.

Dependencies
------------
This module depends on the following module:

- sale_stock

Usage
-----
After installation, the module will automatically apply custom behaviors to the sale stock portal.
