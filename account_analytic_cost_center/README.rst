    Permite segmentar la contabilidad analítica por centros de coste.
    Con este módulo se añade un nuevo campo "Centro de Coste" en los apuntes analíticos
    para poder agruparlos o filtrarlos por este campo.
    Además modifica el widget de la distribución analítica para que se pueda asignar
    fácilmente el centro de coste.
