Sale session Cashdro

Send cashing request to Cashdro during the cashing of a ticket in sale session wizard

Integrar el módulo sale_session con el cobro a través de Cashdro.

Permite enviar la petición de cobro a la máquina Cashdro durante el cobro de un ticket en el asistente de la sesión de venta.

Añade nuevos campos para la configuración de la máquina Cashdro en el modelo de los diarios.

Los nuevos campos se muestran en la vista formulario solo cuando el diario sea de tipo 'Efectivo'.
