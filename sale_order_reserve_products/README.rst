===========================
Sale order reserve products
===========================

.. |badge1| image:: https://img.shields.io/badge/licence-AGPL--3-blue.png
    :target: http://www.gnu.org/licenses/agpl-3.0-standalone.html
    :alt: License: AGPL-3

|badge1|

    * Permite reservar productos desde el pedido de venta.
    * Añade un asistente para reservar productos.
    * Añade un botón para cancelar la reserva de productos.
    * Cuando se confirma un pedido de venta se cancela automáticamente la reserva y se asignan esos lotes en el albarán de salida del pedido.
    * Se añade una acción planificada para liberar albaranes de reserva al pasar un número determinado de días configurable en un nuevo parámetro de sistema.
