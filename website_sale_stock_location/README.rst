Website Sale Stock Location
===========================

- Muestra las ubicaciones del stock de un producto en el sitio web.


Uso
---

- En la sección de "Productos" de Ajustes del Sitio Web, habiendo seleccionado
el sitio web correspondiente, podremos seleccionar en "Ubicación del stock del
producto" el tipo de usuario que podrá ver la información y/o ubicación del
stock del producto, el tipo de usuarios por defecto será "Empleados".
