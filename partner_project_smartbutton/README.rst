Partner Project Smart Button
============================

Este módulo añade un botón (smartbutton) en el formulario de contacto para
acceder a los proyectos asociados al mismo, si el contacto no tiene ningún
proyecto el botón no aparece.

Uso
---

Puede acceder a los proyectos desde el formulario de un contacto, pinchando
en el boton "Projects".

Solamente se mostrara si el contacto tiene proyectos asociados.
