Automatic Translation

Traducciones automaticas con arquitectura extensible de proveedores.

Este modulo permite traducir automaticamente contenido de negocio en Odoo utilizando un proveedor externo de traduccion.

Funcionalidad principal

  • Traduccion de registros individuales desde asistente.
  • Traduccion masiva por modelo: todos los registros, por dominio o por seleccion.
  • Seleccion de campos traducibles de tipo char, text y html.
  • Traduccion a uno o varios idiomas de destino.
  • Opcion para sobrescribir o respetar traducciones existentes.
  • Registro de resultados con exitos, omitidos y errores.

Modelos soportados en traduccion masiva

  • Productos: product.template.
  • Variantes de producto: product.product.
  • Categorias publicas de tienda: product.public.category.
  • Paginas web: website.page.
  • Contactos: res.partner.

Configuracion

La configuracion del modulo se realiza desde Ajustes > Traducciones, en la seccion de Auto Translation.

  • Proveedor de traduccion que se utilizara para generar los textos traducidos.
  • Tiempo maximo de espera para las peticiones al proveedor externo.
  • Numero de reintentos ante errores temporales del servicio.
  • Parametros de lote para controlar las traducciones masivas.

El modulo requiere la dependencia Python deep-translator>=1.11.0.

Como se usa

  1. Ir a Ajustes > Traducciones y configurar Auto Translation: proveedor, timeout, reintentos y parametros de lote.
  2. Para traduccion individual, abrir un producto y pulsar Auto Translate.
  3. Para traduccion masiva, usar Traducciones > Auto Translation > Bulk Translate o la accion contextual desde la lista de productos.
  4. Seleccionar idioma origen, idiomas destino, campos y filtro.
  5. Ejecutar y revisar el Status Log.

Ejemplo real

Una tienda con 800 productos en espanol quiere publicar el catalogo en ingles.

  1. Abrir Bulk Translate.
  2. Seleccionar el modelo product.template.
  3. Seleccionar los campos name y description.
  4. Definir es_ES como idioma origen.
  5. Definir en_US como idioma destino.
  6. Aplicar el filtro de todos los registros.
  7. Ejecutar la traduccion.

Resultado esperado

  • Se crean traducciones en ingles para los campos seleccionados.
  • Si no se marca sobrescritura, no se pisan traducciones manuales previas.
  • El log muestra cuantos campos se tradujeron, omitieron o fallaron.

Notas

  • El texto original del idioma base no se modifica.
  • Las traducciones se guardan en base de datos mediante ir.translation.
