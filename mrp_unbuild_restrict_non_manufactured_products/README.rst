==============================================
Mrp unbuild restrict non manufactured products
==============================================

.. |badge1| image:: https://img.shields.io/badge/licence-AGPL--3-blue.png
    :target: http://www.gnu.org/licenses/agpl-3.0-standalone.html
    :alt: License: AGPL-3

|badge1|

Este módulo añade la siguiente funcionalidad a las órdenes de desconstrucción:

- No permite desconstruir un producto con un lote que no ha sido fabricado previamente.

- No permite desconstruir un producto sin lote si no ha sido fabricado previamente.

- Evita la creación de movimientos de stock para productos de tipo servicio.
