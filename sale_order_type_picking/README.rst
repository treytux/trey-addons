Sale Order Type Picking
=======================

Añade el tipo de venta del pedido relacionado en los albaranes.

El tipo de venta se muestra en las vistas de lista y formulario de albaranes,
y permite agrupar los albaranes por tipo de venta desde la vista de búsqueda.

Características
===============

- Obtener el tipo de venta del pedido relacionado con el albarán.
- Mostrar el tipo de venta en las vistas de lista y formulario de albaranes.
- Buscar y agrupar los albaranes por tipo de venta.

Uso
===

1. Vaya a **Inventario > Operaciones > Transferencias**.
2. Consulte el tipo de venta en la lista o en el formulario del albarán.
3. Utilice la vista de búsqueda para agrupar las transferencias por **Tipo de
   venta**.
