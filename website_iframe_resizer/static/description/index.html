Redimensionado compartido de iframes

Servicio común para las integraciones de Nexmart y Raíz Ferretera. Carga una única biblioteca y adapta los iframes al contenido sin inicializaciones duplicadas, incluso cuando se insertan después de cargar la página.

Los módulos consumidores marcan sus iframes o contenedores mediante las clases js_wir_iframe y js_wir_container.
