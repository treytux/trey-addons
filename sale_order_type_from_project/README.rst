Descripción
~~~~~~~~~~~

Permite definir un tipo de pedido de venta por defecto en cada proyecto.
Al seleccionar un proyecto en un pedido de venta, se aplica su tipo de
pedido configurado.

Uso
~~~

#. Abra un proyecto y seleccione su tipo de pedido de venta.
#. Cree o edite un pedido de venta y seleccione el proyecto.
#. Compruebe que se aplica el tipo de pedido configurado en el proyecto.
