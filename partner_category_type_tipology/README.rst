Este módulo permite marcar etiquetas de contacto como tipologías de cliente y
asociar a cada una porcentajes mínimo y máximo de cumplimiento sobre horas
planificadas.

También añade en la ficha del contacto un campo específico para seleccionar una
única tipología, independiente de las etiquetas generales del partner.

.. contents::
   :local:


Funcionalidad
~~~~~~~~~~~~~

* Permite identificar categorías de partner como tipologías.
* Define porcentajes mínimo y máximo por tipología.
* Añade la tipología seleccionada en la pestaña de ventas y compras del
  partner.
* Carga las tipologías iniciales A, B, C y D.
