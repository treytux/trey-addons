Descripción
~~~~~~~~~~~

Este módulo amplía `project_current_balance` para proyectos asociados a
líneas de `contract_lite`. Añade la bolsa horaria contratada, el periodo de
renovación y el control de facturas pendientes.

Uso
~~~

1. Relacione el proyecto con una línea de contrato de mantenimiento.
2. Consulte el saldo actual según la bolsa horaria contratada.
3. Revise alertas y facturas pendientes desde el proyecto o la tarea.
