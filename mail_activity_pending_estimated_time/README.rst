Añade un campo de tiempo pendiente estimado a las actividades planificadas junto con la
posibilidad de poder ver el sumatorio total del tiempo pendiente estimado en
el dashboard de actividades.

Se añade también el mismo campo de tiempo pendiente estimado a las tareas con el
sumatorio de las actividades planificadas relacionadas.

Uso
~~~

1. Abre una tarea.
2. Añade una actividad, indica el tiempo pendiente estimado.
3. Entra en la actividad, pulsa el botón para ir a su tarea.
4. Mira el total de tiempo pendiente estimado de las actividades de la tarea.
5. Entra en el menú de Dashboard, entra en actividades.
6. Mira la distribución de tiempo pendiente estimado según cómo agrupes las
   actividades; por usuario, por fecha límite, por tarea, etc.
