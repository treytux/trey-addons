Website Sale Payment Custom Autoconfirm
=======================================

- Permite confirmar automáticamente los pedidos de venta realizados con un
  proveedor de pago de tipo custom.
- La opción se configura individualmente en cada proveedor mediante el campo
  «Confirmar pedidos automáticamente».
