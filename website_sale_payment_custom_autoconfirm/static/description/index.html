Confirma automáticamente pedidos de venta con pagos custom

Este módulo permite confirmar automáticamente los pedidos de venta realizados con un proveedor de pago de tipo custom.

La opción se configura individualmente en cada proveedor mediante el campo Confirmar pedidos automáticamente.

El pago continúa en estado pendiente, ya que puede liquidarse posteriormente según las condiciones acordadas con el cliente.

Tabla de contenidos

Configuración

  1. Ir a Website > Configuración > Proveedores de pago.
  2. Abrir un proveedor cuyo tipo sea Custom.
  3. Activar Confirmar pedidos automáticamente.
