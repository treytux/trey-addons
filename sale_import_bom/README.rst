===============
Sale import BoM
===============

Permite importar productos y componentes desde una Lista de Materiales (BoM)
directamente a un pedido de venta.

Características
~~~~~~~~~~~~~~~

* Botón "Add BoM" en pedidos de venta (estado borrador)
* Asistente para seleccionar BoM y cantidad
* Opción para importar solo componentes sin el producto principal
* Calcula automáticamente las cantidades basadas en la BoM
