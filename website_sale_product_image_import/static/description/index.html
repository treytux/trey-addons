Importación masiva de imágenes de productos

Permite cargar imágenes principales y adicionales de plantillas o variantes de producto desde un ZIP nombrado por referencia.

Al actualizar una plantilla se conservan las imágenes propias de sus variantes. Si varias referencias del ZIP apuntan a la misma plantilla, se omite esa plantilla y se informa del conflicto, incluso si algún conjunto tiene imágenes o numeración inválidas y su referencia es reconocible. Los demás productos continúan procesándose.

La comprobación se realiza tanto al validar como al importar. Para resolver un conflicto, use una sola referencia por plantilla o el destino variante para imágenes específicas.
