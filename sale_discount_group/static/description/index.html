Sale Discount Group

Descuentos automáticos por grupos de productos y clientes

Este módulo permite definir descuentos comerciales por combinación de grupo de productos, grupo de clientes y rango de fechas.

Al crear una línea de pedido de venta, si existe una regla válida para la combinación del producto y del cliente, se aplica automáticamente el descuento.

Además, en las reglas de tarifa se añade la opción Apply Discount Group para permitir o bloquear la aplicación del descuento por grupo.

Características principales

  • Grupos de productos y grupos de clientes.
  • Reglas de descuento con fecha de inicio y fin.
  • Aplicación automática en líneas de pedido de venta.
  • Compatibilidad con reglas de tarifa.

Flujo de uso

  1. Crear grupos de productos y de clientes.
  2. Configurar reglas en Discount Group.
  3. Crear presupuesto/pedido y añadir productos.
  4. Revisar el descuento aplicado en cada línea.
