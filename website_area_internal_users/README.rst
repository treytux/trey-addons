Website Area Internal Users
=============================

Este módulo permite la visualización de ciertos menús y páginas solo para
usuarios internos.

Uso
----

- Ir a "Sitio Web > Configuración > Páginas"
- Elegir la página a la cual deseamos limitar el acceso.
- Marcamos la opción "Solo visible para usuarios internos" en las opciones del
formulario.
