Website sale description templates
==================================

    * Añade un selector de plantillas de contenido para las descripción en la ficha del producto.
    * El selector se muestra justo antes de la descripción del sitio web en la ficha del producto.
    * Las plantillas admiten marcas.
    * Se añaden las vistas correspondientes para el listado y edición en modo formulario de las plantillas.
    * Se añade un menú en Ventas > Configuración > Productos > Plantillas de contenido para acceder a las vistas.
    * Se añade un menú en Sitio web > Productos > Plantillas de contenido para acceder a las vistas.
