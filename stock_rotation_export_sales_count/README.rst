Stock rotation export sales count
=================================

Este módulo añade una nueva columna al fichero generado desde el asistente "Exportar rotación de stock" en el menú "Inventario/Informes":
   - Nº de pedidos de venta: cantidad de pedidos de venta con mercancía entregada para ese producto en esa ubicación.
