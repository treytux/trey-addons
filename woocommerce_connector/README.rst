=====================
Woocommerce Connector
=====================

Conector para integrar sitios web de Woocommerce con Odoo.

No es necesario instalar ningún plugin adicional en el sitio web de Woocommerce, pero se recomienda los siguientes:

- Para gestionar los NIF y los impuestos OSS, se usa el plugin "YITH WooCommerce EU VAT Premium"
    https://yithemes.com/themes/plugins/yith-woocommerce-eu-vat/
- Para gestionar los códigos GTIN en WooCommerce, se puede usar uno de estos plugins:
    - "Product GTIN (EAN, UPC, ISBN) for WooCommerce", esta deprecado y no se recomienda su uso
        https://es.wordpress.org/plugins/product-gtin-ean-upc-isbn-for-woocommerce/
    - "EAN for WooCommerce" alternativa recomendada
        link: https://wordpress.org/plugins/ean-for-woocommerce/
