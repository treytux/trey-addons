    * Se añade un campo para el límite de margen en la compañía.
    * Se añade un campo para seleccionar el usuario al que se le va a notificar la actividad planificada.
    * El valor de este campo podrá ser cualquier usuario interno de la empresa o el responsable del equipo de ventas del pedido de venta.
    * Se añade un campo de tipo check para incluir o no las líneas de gasto de envío en el cálculo.
    * La comprobación se realiza cuando se ha confirmado el pedido de venta.
    * No limita ninguna funcionalidad de los pedidos de venta.
