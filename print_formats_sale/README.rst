Configuración
=============

#. En *Contabilidad > Configuración > Modos de pago* tenemos que introducir en
el campo "Notas" la descripción, por ejemplo para "Transferencia bancaria"
pondríamos en "Notas": "Transferencia: número de cuenta del banco"
