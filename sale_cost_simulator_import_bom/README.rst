    Permite importar los componentes de una Lista de Materiales (BoM) en un
    simulador de costes de venta.

Características
~~~~~~~~~~~~~~~

* Botón "Import BoM" en simuladores y líneas en estado borrador.
* Asistente para seleccionar una BoM y nombrar el grupo de líneas.
* Creación opcional de un nuevo grupo o inserción en una línea existente.
* Importación de cantidades, unidades de medida y precios de los componentes.
