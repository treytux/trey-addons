Descripción
~~~~~~~~~~~

Este módulo añade un saldo actual reutilizable para proyectos. El saldo se
calcula restando las horas imputadas desde una fecha base a una bolsa inicial
configurable en el proyecto.

Está pensado como pieza base para otros módulos que necesiten consultar o
mostrar el saldo disponible sin depender de personalizaciones concretas.

Uso
~~~

1. Vaya al proyecto.
2. Configure el saldo inicial y la fecha de aplicación.
3. Consulte el saldo actual calculado automáticamente.
