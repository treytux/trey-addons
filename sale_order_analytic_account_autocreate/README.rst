======================================
Sale Order Analytic Account Autocreate
======================================

Crea una cuenta analitica automaticamente al confirmar un pedido de
venta, usando el nombre del pedido como nombre de la cuenta analitica.

Configuracion
=============

Vaya a *Ajustes > Ventas > Presupuestos y Pedidos* y active
*Autocreate sale analytic account*.

Este modulo es parte del proyecto de `Trey addons <https://www.trey.es>`_.
