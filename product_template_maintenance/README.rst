Descripción
~~~~~~~~~~~

Este módulo añade el campo ``Is maintenance`` en productos de tipo servicio.
Sirve como pieza base reutilizable para clasificar servicios de mantenimiento
sin depender de personalizaciones de cliente.

Uso
~~~

1. Vaya a un producto de tipo servicio.
2. Active el campo ``Is maintenance``.
3. Use el indicador en dominios, lógica de negocio o informes.
