======================
Mail server crm domain
======================

Este módulo añade un campo en los equipos de ventas para configurar el dominio de correo electrónico que se utilizará como remitente y respuesta en los correos salientes.
Sólo se reemplazarán los dominios de los correos electrónicos remitentes que esten contemplados en algún equipo de ventas para evitar reemplazos de remitentes en notificaciones de respuestas de clientes.
