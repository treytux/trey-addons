Website Anchor Rel Attribute
===============================

Descripción
===========

Este módulo nos permite asignarle a los enlaces de una página el atributo Rel
en modo edición del sitio web.


Lógica de Visualización
=======================

None: No se asignará ningún atributo Rel al enlace.
nofollow: Se asignará el atributo Rel nofollow al enlace.
ugc: Se asignará el atributo Rel ugc al enlace.
sponsored: Se asignará el atributo Rel sponsored al enlace.

Configuración
=============
- En "Website > Edit" al pulsar sobre cualquier enlace nos saldrá un
  desplegable con los atributos Rel que podemos asignar al enlace, escogemos el
  que queramos y lo guardamos.
