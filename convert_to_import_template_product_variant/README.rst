Configuración
=============

#. En Ajustes > Conversor > Plantilla de conversor de variantes, se muestra el asistente donde el usuario selecciona el proveedor y sube el archivo a convertir.
#. El usuario hace click en el botón "Convertir", lo que le llevará a otra vista donde se puede descargar el archivo con los campos convertidos.
#. El fichero de salida que genere el conversor, se utilizará en Ajustes > Importar fichero > Importar fichero, seleccionando la plantilla "Plantilla para importar fichero de variantes de productos".
