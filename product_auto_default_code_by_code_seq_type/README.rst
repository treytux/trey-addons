Este módulo asigna automáticamente una referencia interna única a un producto basada en varios parámetros, utilizando un tipo de secuencia definido.

**Tabla de contenidos**

.. contents::
   :local:

Uso
===

1. Configura un tipo de secuencia en la categoría del producto.
2. Al crear un nuevo producto, se generará automáticamente el campo de referencia interna (`default_code`) de acuerdo al tipo de secuencia definido.
3. Este comportamiento se aplica tanto a `product.template` como a `product.product`.
