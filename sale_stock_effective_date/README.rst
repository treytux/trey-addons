=========================
Sale Stock Effective Date
=========================

Hace visible el campo `effective_date` en la vista listado de pedidos de venta
como una columna opcional, permitiendo a los usuarios mostrarla u ocultarla mediante el
selector de columnas.

Uso
=====

Tras la instalación, la columna *Fecha de vigencia* aparece en la
vista de lista de pedidos de venta. Se puede ocultar mediante el selector de columnas.

Este módulo forma parte del proyecto `Trey addons <https://www.trey.es>`_.
