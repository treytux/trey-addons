Print Formats Quality Control
=============================

Este módulo añade un asistente en las Inspecciones de Control de Calidad para
poder imprimir los informes de calidad instalados.

Uso
----

- Ir a la app Control de Calidad
- Seleccionar varias inspecciones o hacer clic en una de ellas.
- En el botón Imprimir seleccionar la opción "Asistente de informes".
- Seleccionar el documento a imprimir y hacer clic sobre el botón "Imprimir".
