====================================
Account analytic line project wizard
====================================

Este módulo añade una vista para ver líneas analíticas dentro de proyectos
permitiendo agruparlas según si están facturadas y ofrece un asistente para
facturarlas.

**Tabla de contenidos**

.. contents::
   :local:

Uso
===

1. Acceda a la aplicación de proyectos y vaya a la pestaña de 'Facturar tareas'
2. Seleccione las líneas a facturar.
3. Seleccione opciones para facturar y pulse en facturar, facturar y abrir o
    crear pedidos.

Comportamiento destacado
========================

* Al intentar facturar líneas sin partner o producto se dará un aviso, existe
  la posibilidad de forzar un producto simultáneamente en las líneas.
