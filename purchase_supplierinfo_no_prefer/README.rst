Purchase Supplierinfo No Prefer
===============================


Permite seleccionar proveedores como no preferentes para evitar que dichos
proveedores estén los primeros en las listas de precios de proveedores, a no ser
que el proveedor no preferente sea el único proveedor en la lista.

Para marcar un proveedor como no preferente entramos en la ficha del mismo
en la pestaña 'Compras y ventas' dentro del grupo 'Compra' marcamos el campo
'Proveedor no preferente'

Una vez que marcamos este campo este proveedor se colocará el último en la lista
de proveedores de todos los productos en los que esté como proveedor.

Si después de marcar un proveedor como no preferente desmarcamos este campo las
listas de proveedores no se restaurarán con el orden anterior, es decir, que
este proveedor seguirá siendo el último, a no ser que se cambie manualmente.

Por otro lado, tanto si intentamos añadir un proveedor, como modificar el orden
de un proveedor en una lista de proveedores de un producto, el sistema colocará
los proveedores no preferentes al final de la lista de manera automática.
