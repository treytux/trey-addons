Website Sale Checkout Skip Payment Terms
========================================

Descripción
===========

Este módulo comprueba si se han aceptado los términos y condiciones en el 
proceso de pago y si no es así muestra el campo en el último paso de 
confirmación.

Esta comprobación es útil en caso de haber omitido la página de pago, que es
donde se encuentra dicho campo.
