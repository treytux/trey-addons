Sale user limit margin
======================

    * Añade un campo en la ficha de usuario con el límite de margen de venta (en %) permitido.
    * Evita que un usuario realice cualquier operación (imprimir, enviar emai...) en un pedido de venta con un margen inferior al establecido en su ficha.
    * Las líneas del pedido con un precio específico para el cliente del pedido quedan excluidas del cálculo del margen.
