Product setup

Este módulo permite configurar opciones personalizadas para productos en la venta, agrupándolas en propiedades y categorías configurables. Añade funcionalidades que permiten definir estructuras de configuración reutilizables sobre los productos y aplicarlas de forma sencilla desde la vista de venta.

**Tabla de contenidos**

.. contents::
   :local:

Uso
===

1. Acceder a *Ventas > Configuración > Configuraciones de producto*.
2. Crear grupos de configuración y asociar líneas con propiedades y opciones.
3. Asignar las configuraciones deseadas a los productos desde su ficha.
