Document Expiry PPE
===================

Este módulo integra las asignaciones de equipos de protección individual
(EPIs) en la documentación de los empleados.

Características
===============

* Añade el tipo de documento **Entrega de EPIs**.
* Permite seleccionar la asignación de EPI correspondiente al empleado.
* Muestra los EPIs en las vistas de documentación y búsqueda.
* Evita asociar una asignación de EPI a un empleado diferente.

Uso
===

1. Acceda a **Empleados** y abra la pestaña **Documentación**.
2. Añada una línea y seleccione el tipo **Entrega de EPIs**.
3. Seleccione la asignación de EPI y complete las fechas de vigencia.

También puede gestionar estos documentos desde **Document Expiry > Employees**.
