Website Lite Vimeo Embed

Snippet ligero y configurable para vídeos de Vimeo

Este módulo añade el snippet Lite Vimeo para insertar vídeos con lite-vimeo-embed y mejorar el rendimiento de carga inicial.

El snippet permite configurar:

  • URL del vídeo de Vimeo
  • Ancho (Width)
  • Alto (Height)

También normaliza automáticamente la URL pegada y aplica miniatura ligera antes de cargar el reproductor real.

Incluye página de demostración en /website_lite_vimeo_embed/demo.
