========================
Website Lite Vimeo Embed
========================

Descripción
===========

Este módulo añade un snippet de Website para insertar vídeos de Vimeo con
``lite-vimeo-embed``.

Funcionalidad principal:

- Snippet arrastrable ``Lite Vimeo`` en el editor de Website.
- Campo de configuración ``Vimeo URL`` en opciones del snippet.
- Normalización automática de URL (vimeo.com y player.vimeo.com).
- Configuración de tamaño mediante ``Width`` y ``Height``.
- Miniatura ligera con carga del reproductor real al hacer clic.
