Website Sale Custom Filters
===========================

Este módulo añade la posbilidad de mostrar una zona bajo la búsqueda con
filtros personalizados. También mueve los filtros de ordenación al nuevo
contenedor.

Uso
===

- En el sitio web pichar sobre el menú "Personalizar" y deactivar o activar la
opción "Show Custom Filters".
