Stock picking edit number
=========================

Descripción
===========

Este módulo permite a los usuarios modificar el número y la fecha de los
albaranes de stock.

Funcionalidades
===============

- Editar el número de los albaranes.
- Editar la fecha programada de los albaranes.
- Evitar números de albarán duplicados.
- Control de acceso mediante grupo de seguridad.

Configuración
=============

Después de instalarse el módulo, asigne el grupo 'Forzar albarán' a los
usuarios que necesiten acceder a la funcionalidad.

Uso
===

Vaya a: Inventario → Operaciones → Traslados

Abra un albarán.

Pulse: Forzar albarán

Modifique el número y/o la fecha y guardar.
