=================================
Product Template Delivery Carrier
=================================

    :target: http://www.gnu.org/licenses/agpl-3.0-standalone.html
    :alt: License: AGPL-3

|badge1|

Este módulo permite asignar métodos de envío específicos a plantillas de
producto y, al añadir envío en un pedido de venta, filtra por el método de
envío que tienen en común todos los productos del pedido, de esta forma
se evita que el usuario pueda seleccionar un método de envío que no es
compatible con los productos del pedido.
