Sale order delivery note
========================

    * Añade un campo en el pedido de venta con las notas para la agencia de transporte.
    * Se añade el campo en la vista formulario del pedido del venta.
    * La información también se almacena en el campo 'delivery_note' creado por el módulo stock_delivery_note.
    * La información se traslada al albarán cuando se confirma el pedido de venta.
