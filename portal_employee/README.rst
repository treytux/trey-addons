Portal Employee
===============
Portal de empleados.

Configuración
-------------
- Desde el menú "Ajustes / Opciones Generales / Sitio web / Solicitudes de ausencia" seleccionar el tipo de ausencia para vacaciones.
- Desde el menú "Ajustes / Usuarios y compañías / Usuarios" marcar en la pestaña "Preferencias" para cada uno de ellos si deseamos "Bloquear el acceso al backoffice".
- Podemos definir las categorías de conocimiento a las que tendrá acceso el usuario a través del campo 'Categorías de conocimiento' de su perfil.
