Account move import

Marco base para importar asientos contables desde ficheros

Este módulo proporciona la interfaz genérica y el contrato backend para importar asientos contables en Odoo Accounting.

Añade un botón Import Moves en los diarios, abre un asistente de importación de ficheros y redirige el proceso hacia métodos específicos de importación implementados por módulos de extensión.

Importante: este módulo base no incluye por sí mismo un parser concreto para ningún formato de fichero. Está diseñado para ser extendido por módulos complementarios que añadan tipos de importación y lógica de parseo.

Qué incluye

  • Opción en el diario para habilitar la importación de asientos.
  • Asistente con subida de fichero y selector de tipo de importación.
  • Patrón de despacho de importación basado en el valor del tipo.
  • Acción de redirección a los asientos importados.
  • Ayuda básica para decodificar ficheros de texto.
