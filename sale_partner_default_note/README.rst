=========================
Sale Partner Default Note
=========================

Este módulo añade un campo en los contactos para que se pueda establecer un
unos términos y condiciones que serán trasladados como notas en los pedidos de
venta cuando se seleccione el cliente, siempre que las notas estén vacias.
