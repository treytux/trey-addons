Print options sale cost simulator
=================================

Este módulo añade un botón **Imprimir** al simulador de costes de venta y abre un
asistente desde el que se pueden incorporar opciones de impresión.

El asistente está preparado como base para seleccionar diferentes informes o
formatos. En esta versión no incluye opciones concretas ni un informe propio.

Características
===============

* Añade el botón **Imprimir** al formulario de simulaciones.
* Permite abrir el asistente desde el menú **Acción** de la vista de lista.
* Incluye permisos de acceso para usuarios internos.
* Proporciona una estructura preparada para futuras opciones e informes.
